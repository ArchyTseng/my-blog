## Today's Study Notes :
### 1.Introduction to Regression Algorithms
#### 1.1 Purpose for learning this course:
- Define Regression
- Compare simple and multiple regression
- Explain applications of regression
#### 1.2 Study Notes:
- Regression Algorithms
  - Linear and polynomial
  - Random forest
  - Extreme Gradient Boosting(XGBoost)
  - K-nearest neighpbors(KNN)
  - Support vector machines(SVM)
  - Neural network
- Recap
  -  Regression is a machine learning technique
     -  Models the relationship between continuous target variables and explanatory features
  -  In **simple regession**, a single independent variable estimates a dependent variable(can be linear or nonlinear)
  -  In **multiple regession**, multiple independent variables estimate a dependent variable(can be linear or nonlinear)
  -  Regression can be used to:
     -  Forecast sales
     -  Predict maintenance
     -  Estimate rainfall
     -  Predict the spread of infectious disease(传染病)

### 2.Introduction to Simple Linear Regression
#### 2.1 Purpose for learning this course:
- Describe simple linear regression
- Explain how simple linear regression works
#### 2.2 Study Notes:
- Linear regression formula:
  - \\(y^{hat} = \theta_0 + \theta_1 x_1\\)
- MSE : mean squeared error 
  - commonly known as ordinary least squares regression(OLS, 普通最小二乘法回归)
- Pros and Cons
  - Pros : Simple and easy to understand
  - Cons : its accuracy can be greatly reduced by outliers
