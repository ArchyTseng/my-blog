## 1.What can I get from this course?
- This PC is specifically designed to help you build the practical experience employers look for. Throughout the program, you’ll apply your skills in hands-on labs and projects that fine-tune your new competencies. You’ll:  
  - Build deep learning models and neural networks using Keras, PyTorch, and TensorFlow.
  <br>学会通过Keras, PyTorch, TensorFlow来创建深度学习模型和神经网络。
  - Implement supervised and unsupervised machine learning models using SciPy and Scikit-Learn, positional encoding, masking, attention mechanism, and document classification.
  <br>通过使用 SciPy, Scikit-Learn, 位置编码，掩蔽，注意力机制和文档分类来学习应用有监督和无监督机器学习模型。
  - Create LLMs like GPT and BERT. 
  <br>创建一个类似 GPT 和 BERT 的大语言模型。
  - Develop transfer learning applications in NLP using major language model frameworks like LangChain, Hugging Face, & PyTorch. 
  <br>使用主流语言模型框架（比如 LangChain, Hugging Face, PyTorch）开发 迁移学习应用。
  - Set up a Gradio interface for model interaction and construct a QA bot using LangChain and LLM to answer questions from loaded documents.
  <br>搭建一个 Gradio 界面实现模型交互，并借助 LangChain 和大语言模型（LLM）构建问答机器人，用于回答从已加载文档中提取的问题。

## 4.Today's Study
- **Modul Name: Introduction to Machine Learning**
- Learn the overview of Machine Learning with Python
  - **Python and its Libraries :** Numpy, Pandas, Matplotlib, SciPy, Scikit-Learn
  - **Machine Learning lifecycle:**
    - Problem Definition
    - Data Collection
    - Data Preparation
    - Model Development and Evaluation
    - Model Deployment
  - **The differences between Data scientists and AI engineering:**
    - Data Type: structured data vs unstructured data
    - Use Case: EDA(Exploration Data Analysis) vs Dicision Optimisation
    - Model Feature: various kinds of models with small scap and smaller parameter size vs foundational model of large scap and large parameter size
    - Process speed: Second ~ Hour vs Days ~ Months
